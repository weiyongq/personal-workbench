# 个人工作台（Personal Workbench）

一个纯静态的个人工作台页面，零依赖、可离线使用，数据保存在浏览器 localStorage。

## 功能

- 🕐 **实时时钟**：时间、日期、星期、按时段问候 + 随机每日一句
- 📋 **待办清单**：添加 / 勾选 / 删除，支持筛选与一键清除已完成
- 🍅 **番茄钟**：25 分钟专注 + 5 分钟休息自动切换，轮次计数
- 🔗 **快捷入口**：常用网站卡片，可自行添加和删除
- ✏️ **随手记**：备忘文本框，自动保存
- 🌙 **主题切换**：浅色 / 深色一键切换

## 使用

直接用浏览器打开 `index.html` 即可，无需任何构建步骤。

也可以启用 GitHub Pages：仓库 Settings → Pages → 选择 `main` 分支，即可获得在线访问地址。

## 技术栈

纯 HTML / CSS / JavaScript，无框架、无构建工具、无后端。
